# Phase 3E-7.5 — KLayout CSC circular arc vs Euler bend

This experiment compares a **single 90-degree circular arc** (the circular part of CSC) with a symmetric **Euler / clothoid bend**. It does **not** compare a complete CSC obstacle-avoidance route, and it does not modify Router v6.4.

Both shapes use 0.5 µm waveguide width and a design minimum radius of 6.25 µm. The Euler bend uses a triangular curvature profile from 0 to 0.16 µm^-1 and back to 0. Circular and Euler paths have the same initial heading and 90-degree final heading but **different endpoints**; endpoint-matched routing is a later phase.

## Run

```bash
cd ~/Photonics/klayout-photonics-pdk
klayout -b -r tests/test_euler_vs_csc_klayout.py
```

Outputs in `tests/phase3e75_output/`:

- `euler_vs_csc_90deg.gds` (circular arc on 1/0, Euler on 3/0, text on 10/0)
- `bend_curvature_comparison.csv`

For plotting, load the CSV in Python, LibreOffice, or another plotting tool. The CSV records **analytical design curvature**; it is not curvature measured from GDS polygon boundaries. The polygon is a sampled approximation and requires a separate verification step for fabrication accuracy.

## Caveats

- KLayout API and generated layout should be verified on the target KLayout 0.30.9 installation.
- Symmetric Euler curve generated by midpoint numerical integration; not connected to the existing `euler_bend.py` API.
- This phase does not prove loss reduction, strict polygon curvature bounds, G2 continuity of complete routed paths, or obstacle clearance.
