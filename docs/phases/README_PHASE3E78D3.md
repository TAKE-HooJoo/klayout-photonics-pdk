# Phase 3E-7.8D-3: curvature-jump score experiment

This experiment uses the CSV generated by Phase 3E-7.8D-1. It does not modify
`router_hybrid_v65.py`, and it does not require KLayout or third-party Python packages.

```bash
cd ~/Photonics/klayout-photonics-pdk
unzip -o ~/Downloads/Phase3E_7_8D3_Curvature_Score_Experiment.zip
python3 tools/experiment_curvature_score.py
```

Outputs: `tests/phase3e78d3_output/score_sweep.csv` and `score_winners.csv`.

The experimental score is `wL*(L/min(L)) + wE*(E/max(E)) + wJ*(J/max(J))`
within each case. Sweep: `wL=1`, `wE=1`, `wJ=0,0.1,0.25,0.5,1,2,5`.
These are sampled geometric diagnostics, not measured optical losses.
The benchmark rows reflect observed outputs from four modes, **not** all internal
candidates of AUTO_QUALITY. Duplicate geometry can appear under multiple modes.
Normalization is relative to each case, so scores across cases are not comparable.
