# Phase 3E-7.8D-5 — Fixed-window curvature diagnostics

## Goal
Investigate high-resolution curvature spikes in D-4 using **fixed physical support** instead of a 3-point stencil whose support shrinks with sampling step. This is an experiment, **not** a verified fix or a photonic loss model.

## Installation
From repository root:

```bash
unzip -o ~/Downloads/Phase3E_7_8D5_Curvature_Window.zip
python3 tests/test_curvature_window.py
python3 tools/analyze_curvature_window.py
```

Requires `tests/phase3e78d4_output/route_centerlines.csv` generated by:

```bash
klayout -b -r tests/export_route_points_v65.py
```

Output: `tests/phase3e78d5_output/curvature_window_sweep.csv`.

## Method
For each arc-length location `s`, interpolate the original centerline polyline at `s-h`, `s`, and `s+h`, with **fixed h=1 µm**. Calculate signed turn angle of the two chords divided by `h`. Integrate its square with the trapezoidal rule on an evaluation grid with spacings 0.5, 0.25, 0.1, 0.05 µm. Evaluate only interior positions with full window support.

This filtered estimator reduces sensitivity to shrinking stencils but **cannot recover smoothness lost in the original polyline**. It smooths genuine CSC jumps as well as numerical artifacts, so do not use the filtered maximum delta as a true curvature discontinuity. For CSC, separately track the nominal `1/R` jump proxy from D-4; exact discontinuity requires analytic segment topology. `max_delta_kappa` still depends on grid spacing; compare the normalized `max_gradient` only at the same window width.

## Interpretation
Compare Euler energy variation across ds with D-4; inspect whether a fixed window stabilizes results. If instability persists, inspect original vertex spacing and corner angles, and compare against analytic Euler curvature. Do not modify AUTO_QUALITY scoring until validated.
